# bettar 岩馆定线工作流

版本：v0.2 · 2026 年 10 月 16 日 · 目标工作流与示例馆第一阶段实现

bettar 帮助定线员在一个具体岩馆的具体区域设计、调整和记录抱石线路。工作的起点是场地与定线意图，工作的终点是可以继续修改、对照实装和回看试攀结果的一份线路记录。

**主流程：打开岩馆 → 选择墙上区域 → 确定风格与大致难度 → 生成并比较 → 手调与辅助修正 → 实装试攀 → 留档。** 日常操作围绕同一块墙体画布展开，以上环节不需要变成七个页面。

本文定义完整的目标工作流和交互取舍；当前已先用示例馆实现选区、生成比较、手动调整及持续保存，能力边界在末尾单列。下文的任意圈画、指定范围修正、实装和试攀场景仍是后续目标，不能读作已经实现。现有运行行为以 [实现契约](implementation-contract.md) 为准。

## 从一次普通定线工作出发

假设我负责两家岩馆。今天到城北馆，准备在入口右侧的屋檐出口补一条中等水平会员能尝试的线路，偏技巧和平衡，希望转出屋檐是主要难点。屋檐与上方墙面连在一起，旁边两条线路需要保留，一个大体积块也暂时不动。

我打开城北馆，看到整体墙形和现有线路，点到屋檐区，在顶棚及出口墙面上圈出本次可用范围。风格和大致难度选好后，生成三个方案。我选中其中一个，保留喜欢的转体动作，把一个手点转了些角度，再请系统只调整出口脚点。系统展示修改前后，我接受有帮助的部分，保存待安装版本。

到现场发现一个脚点不能按图安装，我换到附近的可用位置，记录成实际安装版本。试攀后发现较矮的攀爬者很难完成出口转换，于是补一个脚点，再试一次。最后保存实际开放的版本；下次回到这个馆，能找到当时的布局、修改原因和试攀意见。

这个场景决定了产品需要持续记住场地、设计和修改过程。三条生成结果只是其中一个环节。

## 场地与线路如何组织

| 对象 | 定线员如何理解 | 应保留的关系 |
| --- | --- | --- |
| 岩馆 | 我今天在哪个馆工作 | 馆名称、墙体、分级与颜色习惯、可用岩点库、定线记录 |
| 整体墙体 | 这个馆实际的岩壁形状 | 统一尺度与坐标、相连墙面、屋檐与转角、几何版本 |
| 墙区 | 日常叫的“入口直壁”“右侧屋檐” | 帮助定位的名称；一个墙区可以包含多个几何面 |
| 本次定线区域 | 我这次准备在这里定线 | 墙面上的可安装范围、保留物、可调整物和周边环境 |
| 定线任务 | 今天在这一区域补一条怎样的线 | 区域、意图、生成批次、候选、选定方案及工作进度 |
| 线路版本 | 我修改前后具体摆了什么 | 岩点实体、位置、朝向、安装关系、修改原因、对应检查与试攀记录 |

区域允许跨越相邻墙面，例如从屋檐底面延伸到出口立面。它不能只用屏幕上的二维框表示，也不能因为选择了局部，就把周围墙体和岩点从检查场景中删除。第一版可用面板上的简单多边形与可视化选择表达，复杂扫描曲面后续再接入。

区域边界首先限制**可以安装或移动岩点的位置**。人的身体活动、可能走法及落地方向还要结合周边环境判断；两者不等同。区域外的邻线、体积块、通行与落地条件保留为上下文，现场条件由定线员核对。模型没有覆盖的空间检查明确标为待核对。

整体墙体、可拆装体积块和普通岩点分开记录。移动体积块会影响装在它上面的小岩点，也可能影响多条线路，不能作为某条线路的普通局部修正悄悄完成。

## 建场地与日常定线分开

首次建立岩馆时，先获得一份尺寸可信、能识别相邻关系的墙体。可以从已知尺寸的分面模型开始，给墙区起名；有扫描资料时再导入、定尺度并校对。展示网格与可供算法安装、接触及碰撞检查的几何需要对应，导入成功不等于已经可以生成。

岩点库可以先使用标准模板和现有素材模拟。每个项目必须能分清“模拟库存”和“现场已确认库存”：前者足以产生灵感，但不能直接给出可按库存安装的结论。真实馆录入的岩点要保留数量、颜色、型号或实体标识及安装状态。

完成这些准备后，日常打开时直接回到上次的馆和任务。馆、墙体和资产配置放在场地设置中，不要求定线员每次生成都重新配置。

## 一次定线如何推进

| 环节 | 定线员做什么 | 系统提供什么 | 留下什么 |
| --- | --- | --- | --- |
| 选位置 | 从整体墙形进入墙区，选出本次范围 | 局部放大，同时能看见它在全馆的位置及邻线 | 区域和所依据的场地版本 |
| 定意图 | 选风格、大致难度，必要时补充目标人群或想保留的动作 | 沿用馆内默认库存、颜色与分级；摘要始终可见 | 一份简短定线意图 |
| 生成比较 | 看三个候选，选择值得继续发展的方案 | 同区域、同库存和目标下的不同布局与可能走法；保留失败样本 | 整次生成及三个候选 |
| 手动微调 | 移点、转点、换点或抓握面，调整起终点 | 直接在墙上操作；撤销、回到旧版；旧检查及时失效 | 修改后的版本及差异 |
| 辅助修正 | 选一个问题、动作段或区域，请系统帮忙调整 | 在允许范围内提出修改，重新搜索走法并检查，展示得失 | 被采用或拒绝的建议及原因 |
| 准备安装 | 选定方案，确认准备带到现场 | 区域视图、岩点清单、安装位置和方向、仍需核对的事项 | 待安装版本及库存预留 |
| 实装试攀 | 记录现场偏差，试攀、改点、再试 | 便于手机查看与标注；反馈绑定具体实装版本 | 实装版本、试攀观察和修改记录 |
| 开放与后续 | 确认实际开放的线路，记录后续调整或拆线 | 按馆和墙区回看；拆线后保留历史并释放实体库存 | 上墙记录、后续反馈和归档记录 |

开始定线时只必须确认**区域、风格、大致难度**。任务名可以自动带出馆、墙区和日期，之后再改。目标人群、配色、起终点意图和动作偏好按需补充，避免长表单。难度沿用馆内体系；尚未建立体系时用相对难度表达。

风格允许混合，例如“以技巧为主，出口需要一次发力”。用户可以指定大致难点位置或保留某段动作，但不必预先填写所有动作和阶段。动作构想与岩点布局共同迭代，具体手脚走法由搜索和试攀发现。

### 自由摆点与现有点选线

商业馆新定线默认在选区内新增或重新摆放岩点。现场已有物应区分“保留”“允许调整”“计划拆除”；计划拆除只属于设计方案，确认现场已拆除后才更新真实安装状态。邻线默认保留。

目标方案可以排除计划拆除的点，但检查结果须注明依赖其拆除；确认拆除前，现场视图仍保留这些实体，库存也不能提前变成可用。当前现场与准备实施的目标布局应能清楚区分。

训练墙则可能只需从现有点中选一条线路。这个模式固定实体位置和朝向，生成器只能选点及使用角色。两种模式入口可以很轻，但修改权限必须明确，不能为了让线路通过而暗中移动训练墙或邻线的点。

两种模式都按具体接触面判断手脚权限。手点可以有合法踩面；“这是手点”不能成为统一禁踩理由，类型名称也不能让所有表面自动可踩。

### 三个方案如何值得比较

三个候选共享场地、库存和目标，重点比较实际走向、手脚关系、难点位置及节奏。仅挪动几厘米或改个名称，不能作为“有三种设计”的充分依据。相似方案应标注相似，预算内确实只能找到一个时就如实保留一个。

每张卡片只给方案名称、一句可核对的特点和必要的待确认提示。选中后在同一视角切换布局，需要时回放可能走法。计算支持的特点与定线意图区分显示；没有动态模型时，不给“协调动作已验证”的结论。

跳点和不同走法可以是好线的一部分。是否保留捷径，要看它对目标人群、难度与体验的影响，不能只因没有用完所有点就自动加难或封堵。

三个备选是互斥草稿，可以比较同一批岩点的不同用法，不能扣三次库存。选定待安装方案后才预留具体实体；确认安装后转为占用。其他已安装线路和已预留任务的岩点不再计入可自由使用库存。

## 手动调整与辅助修正如何协作

默认让定线员直接编辑墙上的点。拖动时做边界、安装与重叠等及时提示；编辑完成后标记旧走法和检查为待更新。耗时的重新搜索与优化由明确的“检查走法”或“帮我调整这里”触发，不在每次拖动后抢走操作。

两项动作的含义要清楚：

- **检查走法**：保留布局，重新寻找并检查可能走法；若只复核旧走法，必须明确告知检查范围。
- **帮我调整这里**：允许修改指定范围的布局，再独立搜索和检查。先看提案，采用后生成新版本。

一次局部修正应能表达：“保留起终点和这个难点，只调整出口的脚点，让较矮的人也有转换选择。”目标涉及的体型和能力范围需要记录；单个人体模型的结果不能代表所有人。

| 修正约定 | 具体行为 |
| --- | --- |
| 保留我的设计 | 可以分别锁定位置、朝向、岩点型号或抓握面；人工标记的关键段作为保留意图 |
| 限定改哪里 | 只在选定区域、岩点或动作段附近改动；邻线和未授权的共享体积块不动 |
| 先比较再采用 | 显示改了哪几个点、为什么、哪些问题改善、哪些未解决，以及对原风格和负担的影响 |
| 每次重新找走法 | 修改几何后从新布局搜索，允许原动作顺序变化；不沿用旧顺序制造“修好了”的结果 |
| 接受后可回退 | 采用提案形成版本；撤销或返回原版不丢失历史；部分采用必须重新检查实际采用的组合 |
| 没有更好的就保留 | 范围太小、锁定冲突、库存不足或预算内没找到时说明原因；扩大范围要由定线员主动选择 |

“自动纠正”是定线员明确发起、范围受限、可撤回的一次操作。后续可以允许用户预先选定范围后直接应用局部修正；默认保留预览，手调不会被后台优化静默覆盖。

生成与修正共同遵守以下优先级：先满足已知的区域、库存、安装与锁定约束；再保持定线意图，比较候选动作与检查结果；最后由定线员结合试攀判断体验。支撑通过率是诊断项，不能成为唯一质量分数，也不能把动态创意一律改成静态动作。

AI 提案可以改变布局、合法抓握面和走法，但不能通过降低摩擦检查标准、提高假设握力或更换一个更强的人体来制造通过。对未覆盖的动态、勾脚等动作保留未知，不用静态失败代替真人判定。

## 记录必须能回答当时发生了什么

定线记录自动随任务保存。常规修改不要求填写长说明，关键节点再补一句原因。重新打开后要恢复区域、整批候选、当前方案、修订和备注；保存当前一个结果包不能代替保存整次工作。

| 记录内容 | 必须能追溯到什么 |
| --- | --- |
| 场地依据 | 哪家馆、墙体几何版本、区域和当时保留的周边安装 |
| 定线意图 | 给谁爬、希望什么体验、大致难度及需要保留的关键段 |
| 草稿与修改 | 哪个候选、父版本、谁做的修改或哪次自动建议、实际改变的点 |
| 计算检查 | 对应的布局和场地、使用的假设、通过／未满足／未知及搜索范围 |
| 安装记录 | 从哪份草稿开始，现场实际安装了哪些点，哪里与设计不同 |
| 试攀反馈 | 哪个实装版本、试攀者或匿名代号、必要的体型／能力信息、实际走法与问题 |
| 开放与拆线 | 定线员确认的实际状态、日期及后续变化；拆线后仍可回看 |

设计意见、计算诊断和真人试攀分别记录。模拟回放不填写成试攀记录，数字草稿也不会自动变成“已安装”或“已开放”。现场改点产生新的实装版本，旧版的试攀结论仍属于旧版。

墙体重装、相关邻线或共享体积块变化时，受影响的检查失效；更新算法后可以重查旧草稿，但原始报告作为历史保留。历史版本继续引用当时的场地，不能套上最新墙形后仍展示旧的通过结果。

需要同时表达三个维度：**工作进度**（草稿、待安装、已安装待试攀、已开放、已拆除）、**计算结果**和**试攀记录**。它们互相关联，但不互相冒充。例如已安装的线路仍可有未知诊断，计算通过的草稿也可能尚未有人试过。

## 交互围绕同一块墙展开

首页打开上次使用的岩馆。顶部用简短的馆和墙区名称帮助定位，主体是整体或局部墙体。选区之后，风格、大致难度和“生成 3 条”留在画布附近；不把主流程藏进工具页，也不强制先进入任务管理后台。

生成后，候选卡片出现在同一工作区。点击岩点才显示编辑工具，选中问题才显示局部修正选项。检查详情、资产属性和算法参数逐层打开；默认画面突出墙、当前方案和下一步动作。

记录入口用于继续上次任务和查看旧版，按岩馆及墙区组织。场地与库存管理是低频设置；导入、导出和研究明细放入更多操作。手机优先支持现场查看、定位岩点、补充实装变化与试攀记录，精细建模可先在桌面完成。

后续界面验收看三个实际问题：用户能否找到今天要定的地方；能否在保留自己想法的前提下得到修改帮助；能否明天继续昨天的工作。不要把技术检查清单整体搬成首页导航。

## 现有原型与实施顺序

截至本稿日期，第一阶段已从独立墙形模板推进到可保存的示例馆定线工作，能力边界如下。

| 能力 | 当前状态 |
| --- | --- |
| 岩馆与整体墙体 | 一个明确标为演示的馆，六个结构面共用米制坐标；尚不支持自建馆、多馆管理或真实墙档案 |
| 局部区域 | 仰角、屋檐出口、凹角三个预定义区域；屋檐选区跨三个面，可切换整体和区域视角，尚无任意圈画 |
| 扫描墙体 | 有独立查看和标注入口，尚未成为线路生成的场地输入 |
| 生成三案 | 首页选择区域、风格和大致难度，实时规则生成并独立搜索；18 个可编辑点的完整占地受区域限制，全馆墙面及 14 个邻区点保留为碰撞上下文 |
| 人工编辑 | 能移点、旋转并保留旧候选及包内修订；邻区点固定、不可借用，越界修改被拒绝；逐点人工锁定与撤销尚未实现 |
| 编辑后检查 | 目前复核当前候选的既有接触序列，不会自动重新搜索或修正 |
| 支撑反馈修正 | 已用于首次生成内部；尚无用户指定范围的局部修正入口 |
| 持续保存 | 自动保存区域、条件、三案、修订、当前选择及备注到本机 `.runtime/projects/`；首页恢复上次记录，“定线记录”可重开，保存失败明确提示；无云同步 |
| 导入导出 | 当前馆兼容包导入后新建单案记录；通过校验的独立草稿保持独立编辑、导出。导出当前方案不代替整批记录保存 |
| 库存与现场反馈 | 有单请求库存和设计备注；尚无馆级预留、实装记录及真人试攀记录 |

按三个可验证阶段推进，每阶段继续复用同一画布。

**第一阶段：在具体场地持续定线。** 本轮用示例馆和模拟库存实现这一闭环，首页只要求区域、风格和大致难度；选择区域使用实际面板坐标和安装边界，整次三案工作可以保存并重新打开。“更多 → 新定线”另开一份记录，低频资料和研究参数不占据主流程。区域当前是预定义矩形片区，背景点只是明确冻结的演示安装，并非经过验证的真实邻线。全馆自动扫描、自建馆和任意圈画不作为本轮交付内容。

仰角、屋檐各三条固定条件实跑均找到完整且离散几何通过的走法；两组各有三种布局及三种接触序列，仍有静态支撑问题。区域权限、完整足迹、邻点碰撞及导入约束验证见 [示例馆记录](../outputs/example-gym/README.md)。凹角输入与几何已验证，本轮六案实跑不包含凹角，不宣称所有区域都保证成功生成。

**第二阶段：保留人工意图的协同修改。** 完成可撤销修订、分项锁定、布局不变时重新搜索走法，以及指定范围的辅助修正。修改前后可比，不能改邻线或破坏锁定；记录接受和拒绝的原因。重点验证是否减少有用方案的修改成本。

**第三阶段：接上现场记录。** 从选定方案形成待安装版本，区分库存预留与实际占用；记录实装偏差、试攀、再次修改、开放与拆线。真实反馈先用来修正规则和暴露模型盲点，不要求自行训练模型。

当前优先级是这条工作链。多人协作权限、营业管理、自动排换线计划、完整动态仿真和通用扫描自动配准可以后续按需要扩展，不作为首轮使用门槛。

## 用场景验收

1. 同馆有直壁、仰角和屋檐。进入屋檐出口区域后仍能定位全馆位置，生成使用该处原有几何，不替换成通用单面墙。
2. 选区跨顶棚与出口面。新点的安装占地在允许范围内，邻线和共享体积块仍保留，未授权点不被移动或借用；上下文覆盖不足时如实提示。
3. 同一区域生成三案，能看出实际布局或走法差别；相似、失败和未检查的方案不会靠名称伪装成成功。三个备选不重复占用实体库存。
4. 修改 B 案的手点方向后，新版旧检查失效，原版仍可恢复。保存并重新打开，区域、全部候选、当前版本及备注都在。
5. 锁定起终点和关键手点，请系统“只调出口脚点”。实际建议遵守锁定、选区和库存，能查看差异、拒绝或采用，并能回退。
6. 每个自动修正提案重新搜索并检查；没有更好结果时保留原版，不降低标准，也不把预算内未找到写成不可攀。动态意图不因静态失败被自动抹掉。
7. 现场将一个脚点换了位置，形成新的实装版本，试攀意见绑定该版本；设计备注和模拟结果不会计为真人试攀。
8. 共享体积块或相关邻线改变，关联检查及时失效，历史仍能重现旧场景；拆线释放实体库存，保留线路及试攀历史。

## 职业实践依据

[CWA Routesetting Guide 的官方介绍与摘要](https://hub.cwapro.org/AssetListing/Resources-7639/CWA-Routesetting-Guide-20996)把馆内定线放在持续运营中讨论，涵盖岩点管理、换线、线路追踪、目标用户、试攀及线路质量与多样性。这支持把生成放进完整的馆内工作链。

[ABC 商业定线培训路径](https://www.abcwalls.co.uk/rsd-pathway/)涵盖拆装、商业定线的工作量、团队协作与质量，并要求记录定线实践天数；商业路径与竞赛方向分列。因此本稿以普通岩馆工作为主场景，比赛线路作为动作与设计参考。

上述资料提供职业实践背景；局部选区、草稿库存预留、AI 修改权限和版本交互是 bettar 的产品设计决定，后续需要通过定线员实际使用验证。
