# 示例岩馆：区域生成与持续定线

记录更新：2026-10-16。场地 `bettar-demo`，版本 `demo-gym-1`；生成器 `rules-draft-options-v3`。

本轮把 [岩馆定线工作流](../../work/routesetter-workflow.md) 的第一阶段接到一个明确标为演示的场地：看整体墙形，选局部区域，再选风格和大致难度生成三个方案。场地不是实测岩馆，库存和邻区安装均为演示数据。

六个结构面共用米制坐标；三个预定义区域是左侧 25° 仰角、中部屋檐出口、右侧凹角。屋檐区域跨下方立面、水平顶棚和出口立面。区域由面内矩形片区组成，当前不能任意圈画。每案有 18 个可调整点，同时保留全馆墙面及 14 个不可借用、移动或删除的邻区点；完整安装占地受区域限制。

定线记录自动写入本机 `.runtime/projects/`，包含区域、生成条件、三案、各方案修订、当前选择与备注。下次打开可恢复，也能从“定线记录”重开；“更多 → 新定线”开始另一份工作。导出仍是当前方案的单独备份，不是整批记录导出。手调后的检查复核既有接触序列；指定范围的 AI 修正、人工逐点锁定、实装及试攀记录尚未实现。

两组分别有三个不同的布局摘要和三个不同的接触序列摘要。六案均独立搜索，不要求用完所有点，没有接触邻区岩点；全部仍有静态支撑问题。完整离散走法与几何通过不等于真人能连续完成，更不等于可以直接开放线路。风格是生成意图，大致难度不是经标定的 V 等级。

每案搜索、姿态检查和支撑反馈共用 40 秒预算，当前静力报告及最终校验可以在预算后完成。本机六案约 40–41 秒/案；机器负载可能改变预算内检查数量，因此固定种子保证布局提案可复现，不保证每次时限搜索选择完全相同的走法。本轮六案未覆盖凹角实际搜索，不承诺任意区域、风格和种子都能找到完整走法。

复现（不需要机器学习模型）：

```sh
.venv/bin/python scripts/run_example_gym_smoke.py
```
