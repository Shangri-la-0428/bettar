# 首例场景与动作知识卡

日期：2026-10-14｜准备稿｜依据：战略 v0.2

本文只确定首轮实验输入和知识卡，不包含实现或已求解结果。全部数值均为拟议默认，未经真人验证；场景、库存和人体来源标记为 `synthetic_assumption`。来源枚举统一为 `synthetic_assumption`（合成假设）、`observed`（直接观测）、`derived`（推导结果）；推导结果保留输入来源，不因经过计算而变成实测。坐标轴、骨架定义、求解容差和结果字段沿用技术契约。

## 1. 场景与首轮边界

默认使用宽 3 m、沿墙面高度 3 m 的垂直平墙。10° 仰角仅作为后续变体，指相对垂直方向向攀爬者一侧倾斜；沿墙面高度仍为 3 m，变化后重新检查几何。可安装区域距墙边留 0.2 m，按岩点安装投影轮廓检查。岩点之间依据实际尺寸、朝向和包围体检查重叠；不以统一中心距离替代尺寸检查。

库存共 16 个物理实例：6 个 `jug`、4 个 `directional_edge`、6 个 `foothold`。每个实例有唯一 ID、尺寸、接触区域和来源标记；同一实例不能同时安装两处。T01 生成时固定并保存各实例的宽、高、突出深度和局部接触区域。这些程序生成的几何代理均为实验假设，名称不能推出抓力、摩擦或真人等级。首例允许只用部分库存。

同一场景生成器提供两种模式：自由摆点时可调整允许的实例位置与朝向；固定板参照时锁定这些布局变量，只选择接触点和动作顺序。两者共用库存、骨架和检查器，便于观察放开变量后的变化。锁定的合成场景不冒充真实 MoonBoard 数据。

首轮限制为 2–4 次手移动，脚步另列。先做各关键状态的几何与完整骨架逆运动学（IK）检查；负荷、摩擦、动态平衡、连续中间轨迹及人体完整碰撞检查均为 `not_checked`。动态跳跃、脚跟挂钩和脚尖勾挂暂不纳入。三个接触点仍在墙上只是接触记录，不是稳定性证明。

## 2. 两套合成人体与最小单例

A、B 是两个几何测试样例，不代表人口分位或能力等级。所有肢段独立设定；不根据身高同比缩放全部参数。下表是提交技术契约讨论的建议值，最终实验必须保存完整参数版本。

| 几何变量（m） | A | B |
|---|---:|---:|
| 上臂／前臂骨长 | 0.28／0.25 | 0.32／0.28 |
| 大腿／小腿骨长 | 0.40／0.38 | 0.45／0.43 |
| 肩宽／髋宽 | 0.34／0.26 | 0.40／0.30 |
| 肩中点至髋中点 | 0.43 | 0.49 |

P0 默认以腕、踝关节代替接触端点，偏移为零；不建模手指、鞋面或接触朝向。肩、髋的转动轴、参考零位及合成限位由同一骨架模型定义，在实施首个正向运动学（FK）样例前冻结；肘膝屈曲范围暂取 0–140°。这些仍是待补齐并保存的合成配置，不是已取得的完整实测人体资料，也不能在某候选失败后临时放宽。

**先建立一个可回查的几何单例，再设计动作片段。** 选择 A，构造一组符合骨长与限位、非完全伸直的完整骨架姿态；由正向运动学导出四个接触端点，将合成岩点接触区域布置到对应位置，并检查墙内安装与重叠。再用这些目标反求 IK，应找到满足同一模型容差的姿态，不要求恢复完全相同的关节角。若找不到，先排查坐标、端点和求解设置，不将其解释为动作不可攀。当前尚未构造或验证该单例。

## 3. 详细首例：脚先移动，再完成两次手移动

目的：检验“保持手接触，改变脚位，随后改变手位”能否被完整记录并逐状态检查。首例先用 jug 手点和独立脚点，侧拉作为下一张卡的变化。LH、RH、LF、RF 分别表示左右手、左右脚；以下标签是待绑定库存的角色，接触坐标由后续求解确定。

| 顺序 | 事件 | 事件后的接触记录 |
|---|---|---|
| S0 | 起始状态 | LH=J1，RH=J2，LF=F1，RF=F2 |
| S1 | LF 重定位至 F3 | LH=J1，RH=J2，LF=F3，RF=F2 |
| S2 | 第一次手移动：RH 至 J3 | LH=J1，RH=J3，LF=F3，RF=F2 |
| S3 | RF 重定位至 F4 | LH=J1，RH=J3，LF=F3，RF=F4 |
| S4 | 第二次手移动：LH 至 J4 | LH=J4，RH=J3，LF=F3，RF=F4 |

每个事件还记录移动肢体暂时无接触的状态，其他接触保持。所有状态共用同一套骨长、关节限位和环境；骨盆与躯干可以改变姿态，不能逐手脚独立伸缩来“够到”。静态解之间的连接仍未检查；不得据此播放成“已经验证的攀爬”。不预设 F3 必须高于 F1，也不预设脚先移动一定优于先抬手。

首例只交付布局候选、接触顺序、逐状态结果与未知项。若几何不满足，允许移动目标点、改另一只脚先动或换手顺序；保留原方案及修改原因。

## 4. 三张动作卡

来源等级：**教学依据**是已查资料中的定性经验；**设计推断**是我们据此提出的候选关系；**合成假设**是实验数值。三张卡均无实测受力、成功率或难度标定。卡 2、卡 3 只描述局部接触关系，需要与其他事件组合成完整片段；最终每段仍须有 2–4 次手移动，脚步单列。

### 卡 1：脚先移动再抬手

- **目的与接触：** 尝试改变身体位置以接近下一手点；起点四肢有接触，先 LF 换点，再 RH 换点，其余接触按事件记录。对应首例 S0–S2。
- **变量：** 新脚点位置、目标手点位置、骨盆位置、关节配置和左右镜像。
- **能检／不能检：** 可检查库存、接触区域与同骨架关键姿态；不能判断脚点是否承担足够载荷、换点途中是否失衡或动作是否省力。
- **失败与替代：** 新脚点虽更高却让髋膝过度折叠；关键姿态各自成立但无法连接。可降低或侧移脚点、换另一脚先动、先换手，均重新检查。
- **依据等级：** [REI 技术教学](https://www.rei.com/learn/expert-advice/climbing-techniques.html)提供脚步与身体位置经验；本卡的事件顺序是设计推断，非来源保证。

### 卡 2：侧拉横移

- **目的与接触：** 尝试借助侧向手点组织横移；起点 LH 接触 E1、RH 接触 J1，双脚各有接触；终点 RH 移至横向目标 J2，LH 仍接触 E1。脚步需要变化时另列。
- **变量：** E1 朝向、目标横向距离、脚点位置、躯干朝向及身体样例。
- **能检／不能检：** 可检查方向元数据是否存在、安装旋转是否正确、目标是否有关键姿态解；不能由箭头方向直接判定受力成立，P0 不验证抵消侧拉所需的脚力和摩擦。
- **失败与替代：** 手可触及但身体扭转超限，或假定的对抗力不存在。可改脚位、旋转 E1、缩短横移或增加中间手点；新增手移动仍计入上限。
- **依据等级：** [Lattice 运动概念](https://latticetraining.com/blog/learn-100-climbing-techniques-with-just-4-movement-concepts)与 REI 提供方向、身体位置经验；具体布局为设计推断。

### 卡 3：脚点重定位

- **目的与接触：** 在双手保持接触时，尝试为下一动作改变脚位；起点 LF=F1、RF=F2，终点 LF=F3、RF=F2；LF 离开期间单独记录。
- **变量：** F3 的高度与横向位置、接触区域、骨盆配置及下一目标手点。
- **能检／不能检：** 可检查脚能否在完整骨架限位内到达、点位是否重叠；不能证明离脚后的稳定性、踩点精度、鞋面摩擦或卸载过程。
- **失败与替代：** 终点够得到但移脚通道受阻，或姿态改善了脚位却使下一手点不可达。可换 RF 先动、使用另一脚点或暂不移脚；不以脚点更近判定更容易。
- **依据等级：** REI 与 Lattice 提供脚步调整的定性依据；本卡只采用异点重定位，不把同点换脚或勾挂纳入首轮。

## 5. 对接与通过条件

PRD 使用本文件的场景、事件数和三张卡；技术契约拥有具体骨架、坐标和数值容差。第一道门槛是合成几何单例能够回查，其后才生成首例候选。记录应区分“找到模型内姿态”“明确违反已检约束”“未找到解／无法判断”，并保留所有 `not_checked` 项。三张卡用于提出与修改方案，不承担自动验线、真人等级或安全认证。
