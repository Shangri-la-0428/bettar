# 验收执行矩阵

日期：2026-10-14。依据 `work/implementation-contract.md`、03 实验与验收及 02 几何契约。此目录只负责验证，不修改引擎以迎合断言。

测试数据是手工构造的合成输入。结构／几何反例将 IK 预算设为零，检查明确违规是否独立识别；真实 IK 单独运行，使用已知姿态生成接触目标、不同初值求解，并独立复核骨长、关节范围及接触残差。未求解姿态不得输出伪造关节点。

| 验收 | 自动检查 | 浏览器／人工项目 |
|---|---|---|
| AC01 | 版本、缺字段、非有限数、类型／单位错误 | 导入失败保留原视图，错误定位 |
| AC02 | 合法子集、不存在与重复占用库存 | 高亮相关岩点 |
| AC03 | 0.2 m 边距、完整旋转包围体、边缘越界、10° 墙角与 90° 安装角的手算坐标 | 显示与计算使用同一坐标 |
| AC04 | 分离、重叠、刚好接触、容差间距 | 冲突说明是保守近似 |
| AC05 | 手算 FK、骨长／关节范围、真实 IK 与独立复核 | 三维关节点与结果对应 |
| AC06 | 双手保守上界，含末端偏移与接触容差 | 显示测值及模型边界 |
| AC07 | 零预算／未收敛为 unknown，无伪姿态 | 未知状态易于识别 |
| AC08 | 力、平衡、人体碰撞、转换、等级始终未检查 | 无整体可攀／安全通过暗示 |
| AC09 | 生成预算、失败保留、确定性重放 | A/B 策略来源、人工和模型成本须在实际实验另记 |
| AC10 | 条件改变使指纹变化，旧评价不能重用 | 编辑后 stale 与历史版本展示 |
| AC11 | 字段／库存顺序不影响语义哈希 | 同相机比较 |
| AC12 | 缺失、篡改、未知版本；重新生成摘要后的评价结构错误、错误关节点、未知却带姿态、summary 矛盾、空 review 条目 | 截断 JSON 与导入错误；不执行包内文本、不读取任意路径。当前 wire 不含外部资产加载能力 |
| AC13 | 结果和候选关联可检查 | 同视角切换、步骤、反馈导出由浏览器验收 |
| AC14 | JSON 往返、内容改变与哈希校验 | 导出再导入复查 |
| AC15 | 固定模式位置和朝向锁定 | 不静默转换模式 |
| AC16 | 接触引用／肢体、单肢体事件链、手部计数、起终点；原点松开再抓不算换点／脚重定位 | 序列合法不等于动态可行 |

运行入口：仓库根目录执行 `.venv/bin/python -m pytest tests -q`。测试用例与实际执行结果见本目录的测试文件和 `RESULTS.md`（完成运行后写入）。自动测试通过不代表浏览器验收、A/B 对照或真人可攀结论已经完成。
